# CONSOLE BOSS FIGHTING GAME MADE IN PYTHON
# Description
That's an Boss fighting game, where you should beat Boss to Win! 
You have 3 things you can do while you're fighting:
    - Attack
    - Heal up
    - Run away

# Features
  - You can run away and then, game will be over. An Easter egg to Undertale:3
  - You can heal up, so Boss won't beat you!

# Tech stack
It was made in Python 3.14.7 using library called "Random".

# Installation setup
  - clone repository:
    
  -     git clone https://github.com/ruslanmatkovskyi/boss-fighting-game.git
